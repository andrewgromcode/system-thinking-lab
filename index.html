The method

Extreme Programming, adapted for AI

AI is an active development partner: it generates code, proposes solutions, writes tests and explains details. The thinking and the engineering decisions stay with you.

  1. 01Define problems and expected outcomes
  2. 02Establish requirements and acceptance criteria
  3. 03Decompose problems into manageable tasks
  4. 04Design system behavior and architecture
  5. 05Write tests and define verification methods
  6. 06Delegate implementation to AI
  7. 07Read and understand the generated code
  8. 08Verify actual behavior against expectations
  9. 09Identify defects and investigate their causes
  10. 10Refactor and continuously improve the solution

One continuous cycle

Every exercise is an investigation

  1. Problem
  2. Analysis
  3. Modeling
  4. Hypothesis
  5. Tests
  6. AI implementation
  7. Verification
  8. Reflection
  9. Improvement

You do not simply complete exercises. You investigate how systems work, compare expected and actual behavior, and build increasingly sophisticated mental models.

Learning through practice

Six connected environments

HTML & CSS

Document structure, browser rendering, layout systems, responsive behavior, and how markup becomes visual output.

JavaScript

Algorithmic thinking, abstractions, data structures, functions, objects and application logic.

Playwright

Automated browser tests to investigate behavior, interact with the DOM, measure rendered elements and verify hypotheses.

Test-driven development

Describe expected behavior before implementation. Tests become an executable specification.

Code reading

Understand code, recognize patterns, evaluate implementation quality, and explain why a solution works.

Architecture

From single expressions and functions to modules, applications, component interactions and complex systems.

What you will achieve

An independent, AI-capable engineer

Someone who can understand problems, design solutions, evaluate implementations and build reliable systems.

  • Translate ambiguous problems into clearly defined engineering tasks
  • Break complex systems into understandable components
  • Identify relationships, dependencies, constraints and underlying rules
  • Model behavior with algorithms, data structures and abstractions
  • Write and understand JavaScript independently; build interfaces with HTML and CSS
  • Read, analyze and evaluate AI-generated code
  • Design tests and acceptance criteria before implementation
  • Verify real software behavior with Playwright and TDD
  • Delegate implementation to AI while keeping control of technical decisions
  • Find root causes of defects instead of fixing symptoms
  • Refactor and evolve software without losing control of its complexity

Without AI, too

Generating code is not understanding a problem

As code generation gets easier, formulating precise problems, recognizing abstractions, weighing alternatives and verifying results matter more. You will also work without AI: independent problem-solving keeps your technical competence and intellectual autonomy intact.

The culminating challenge

Build your own programming language and compiler

One project that brings together algorithmic thinking, formal structures, language processing, testing, architecture and system design.
